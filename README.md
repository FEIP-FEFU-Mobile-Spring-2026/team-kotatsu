## Студенческий проект: team-kotatsu. FEFU Store 2.0. 
### Описание
Мобильное приложение мобильное приложение-клиент для магазина
FEFU Store. Реализованы экран каталога с фильтрацией, bottom sheet с карточкой товара, содержащая детали, экран корзины с оформлением заказа, а также bottom sheet успешного оформления заказа. Имеется оффлайн режим и кеширование с использованием Room. Реализованы unit тесты, используется linter. Данные для приложения подтягиваются через API.

**Стек** - Android Native (Kotlin, Jetpack Compose).

### Инструкция по сборке проекта

Для сборки проекта понадобятся **Android Studio** (последней версии) и установленный **Git**.

#### 1. Клонирование репозитория
Откройте терминал и выполните команду:
```bash
git clone https://github.com/FEIP-FEFU-Mobile-Spring-2026/team-kotatsu.git
```

#### 2. Импорт в Android Studio
1. Запустите **Android Studio**.
2. Выберите **File -> Open...** (или **Open an Existing Project**).
3. Укажите путь к корневой папке репозитория и нажмите **OK**.

#### 3. Синхронизация Gradle
1. Дождитесь синхронизации Gradle.
2. Убедитесь, что у вас есть активное подключение к интернету.
3. Если синхронизация не началась автоматически, нажмите иконку **Sync Project with Gradle Files**.

#### 4. Запуск и сборка APK

* **Запуск на устройстве/эмуляторе:**
  Подключите Android-смартфон по USB (с включенной отладкой) или запустите эмулятор, затем нажмите зеленую кнопку **Run**.

* **Сборка готового APK-файла:**
  Перейдите в меню **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**. После окончания сборки нажмите на всплывающее уведомление **Locate**, чтобы найти файл `app-debug.apk`.
